# SmartSpend – Intelligent Expense Categorizer

SmartSpend is a desktop application developed using Python that helps users manage personal expenses through an explainable, rule-based AI system.

**Features**
- Automatic expense categorization using predefined keyword rules.
- Expense tracking with date, description, amount, and category.
- User feedback and saved category corrections.
- Dashboard showing total spending, transaction count, and top spending category.
- Search and filter expenses by description or category.
- Delete transactions and export expense records to CSV.
- Persistent local storage using SQLite.

**Technology Stack**
- Python 3
- Tkinter for the graphical user interface
- SQLite for local database management
- CSV module for exporting records

**AI Approach:** Rule-based reasoning using a knowledge base and inference engine.

**Dependencies:** Python standard library only. No external dataset, API, pandas, or scikit-learn required.

**Purpose:** An academic AI mini-project demonstrating knowledge representation, rule-based reasoning, explainable categorization, and user-feedback-based rule updates.
